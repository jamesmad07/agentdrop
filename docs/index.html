About & security

How Agent ID is used. The board contract (view on BscScan) gates every claim with the official Agent ID contract (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F): it requires balanceOf(claimer) > 0, reads the claimer's handle via handleOf(address), and records that handle in the Claimed event, permanently binding each badge to a .ai name.

No custody, no approvals. The contract never receives or holds user funds, has no withdraw function, and never asks for token approvals. Claiming is a single transaction that costs only network gas (about $0.003).

Owner permissions (complete list). The contract owner can only: (1) create drops, (2) activate/deactivate a drop, (3) correct a drop's time window. The owner cannot mint badges for anyone, cannot change the Agent ID gate, cannot alter past claims, and cannot move or take anyone's badge. The contract is not upgradeable. Full source is public and verified on BscScan.

Badges are collectibles. AgentDrop badges are non-transferable memorabilia. They carry no monetary value, and no returns, yield, income, or profit of any kind are promised or implied.

Using an Agentic Wallet? You can also claim through your agent by asking it to call claim(dropId) on the board contract — you will confirm the transaction in your app as usual. This site only uses a standard injected wallet connection; it never asks you to scan a pairing code or to hand over a session.

Open source. The full contract source, test suite, security summary, and owner-permission disclosure are public in the GitHub repository.
